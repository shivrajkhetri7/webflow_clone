## Installation

1. **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd webflow_clone/client
    ```

2. **Install dependencies:**
    ```bash
    npm install
    ```

3. **Start the development server:**
    ```bash
    npm run dev
    ```
